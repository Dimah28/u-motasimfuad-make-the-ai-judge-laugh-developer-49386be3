Entry for make.fun bounty **Make the AI Judge Laugh: Developer Excuses**
($3 pool, top 10 paid): one funny single-line excuse a developer gives
when code breaks in production, judged pairwise by an AI comedy writer
on subject, twist, developer voice, tightness, and freshness.

`main.py` (Python 3, standard library only) writes one line to
`/output/entry.txt`:

> The code passed all 400 tests, then met one real user and immediately forgot everything it knew.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
